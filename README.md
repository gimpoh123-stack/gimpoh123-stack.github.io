# 김포 음식 메뉴 추천

김포시 음식점 현황 자료를 기반으로 음식점을 추천하는 GitHub Pages용 정적 웹앱입니다.

## 기능

- 조건이 없으면 전체 데이터에서 랜덤 추천
- 음식 종류, 지역, 가격대, 식사 상황, 메뉴 취향, 검색어 기반 점수 추천
- 조건 일치 결과가 없을 때 핵심 조건만 남겨 대체 추천
- 지도 보기와 네이버 검색 링크 제공
- 별도 서버나 데이터베이스 없이 index.html, style.css, script.js, data.json으로 동작

## 데이터

현재 data.json에는 첨부 CSV와 XLSX 통합 자료에서 운영 상태인 음식점 867건을 반영했습니다.

 867건

공공데이터에는 상세 메뉴와 가격이 부족하므로 상호명과 업종명 기반으로 대표 메뉴 태그를 추정했습니다. 실제 메뉴, 가격, 영업 여부는 방문 전 링크에서 확인해야 합니다.
